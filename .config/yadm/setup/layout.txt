# Directories every computer should have, relative to $HOME.
# Optional filters: profile:mac|linux|cluster  class:laptop|studio|linux|cluster|server (comma-separated lists allowed)
# "check" = report if missing, never create (another program owns it).
# "ignore" = a top-level glob some computers have (cloud sync, vendor folders); never created, never reported
#            as unplanned. Globs have no spaces, so "Google*" stands for "Google Drive".
# "link:<target>" = make the path a symlink to ~/<target> once that exists; reported while it is absent.
# "unlink" = a top-level glob for symlinks an app re-creates in ~ at every launch (Google Drive, OneDrive);
#            removed on every sync. Only symlinks are ever removed, and the real folder lives under ~/cloud.
