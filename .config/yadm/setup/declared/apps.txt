# GUI apps on the Macs (/Applications, ~/Applications, /System/Applications).
# Format: `entry  key:value ...  [allowed]` and `#` comments, as in layout.txt. The trailing tokens that contain ':'
# or are `allowed` qualify the entry; everything before them is the entry, so names may contain spaces.
# class:a,b = wanted only on those classes (default: every machine of the kind); allowed = may be present, never reported
# (a name may have a wanted line and an allowed line). Sync reports missing and undeclared entries and never removes any;
# `converge adopt apps` appends this machine's undeclared entries as allowed lines.
# source: is required: brew (a Brewfile cask installs it; cask:<token> when the token is not the name lower-cased with
# dashes), release (setup/apps.json and the Search CLI launcher: the apps phase), mas (App Store), manual
# (url:https://... to download it), system (part of macOS). Apple's own apps (/System/Applications, Safari, iWork) are
# never reported as undeclared.
